# 기능 목록

## 현재 구현된 기능

### 1. 네이버 로그인 (OAuth 2.0)

✅ **구현 완료**

- 네이버 계정을 통한 소셜 로그인
- OAuth 2.0 표준 프로토콜 사용
- 안전한 토큰 기반 인증
- 자동 로그인 상태 유지 (localStorage)
- 로그아웃 기능

**사용 방법**:
1. 메인 페이지에서 "네이버 로그인" 버튼 클릭
2. 네이버 로그인 페이지로 리다이렉트
3. 네이버 계정으로 로그인
4. 권한 동의 후 앱으로 돌아옴
5. 사용자 정보 자동 표시

### 2. 사용자 정보 표시

✅ **구현 완료**

로그인 후 다음 정보가 표시됩니다:
- 이름
- 이메일
- 닉네임 (네이버 프로필)

### 3. 네이버 카페 게시글 읽기

⚠️ **부분 구현** (샘플 데이터)

현재는 샘플 데이터를 표시합니다. 실제 카페 API를 사용하려면 추가 설정이 필요합니다.

**현재 기능**:
- 카페 URL 입력 인터페이스
- 게시글 목록 표시 (샘플)
- 게시글 제목, 작성자, 날짜 정보

**실제 API 사용을 위한 요구사항**:
- 네이버 카페 API 권한 신청
- 카페 관리자 권한
- API 엔드포인트 구현 업데이트

### 4. 반응형 디자인

✅ **구현 완료**

- Tailwind CSS를 사용한 반응형 레이아웃
- 다크 모드 지원 (시스템 설정에 따라 자동)
- 모바일, 태블릿, 데스크톱 최적화

### 5. Vercel 배포 지원

✅ **구현 완료**

- 자동 빌드 및 배포
- 환경 변수 설정
- 프리뷰 배포 (PR 생성 시)
- 프로덕션 배포 (main 브랜치)

## 향후 추가 예정 기능

### 1. 랜덤 뽑기 기능 🎲

- 게시글에서 랜덤으로 당첨자 선정
- 중복 제거 옵션
- 당첨 결과 저장 및 내보내기
- 당첨 확률 조정

### 2. 카페 게시글 실시간 읽기 📖

- 실제 네이버 카페 API 연동
- 게시글 검색 및 필터링
- 페이지네이션
- 게시글 상세 보기

### 3. 관리자 기능 ⚙️

- 이벤트 생성 및 관리
- 참가자 관리
- 당첨자 이력 관리
- 통계 및 리포트

### 4. 알림 기능 🔔

- 당첨 시 알림
- 이벤트 시작/종료 알림
- 이메일 알림 (선택사항)

### 5. 데이터 저장 💾

- 데이터베이스 연동 (PostgreSQL/Supabase)
- 이벤트 이력 저장
- 사용자 설정 저장

## 기술 스택

### Frontend
- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **State Management**: React Hooks

### Backend
- **API Routes**: Next.js API Routes
- **Authentication**: OAuth 2.0 (Naver)
- **HTTP Client**: Axios, Fetch API

### DevOps
- **Hosting**: Vercel
- **CI/CD**: Vercel 자동 배포
- **Version Control**: Git/GitHub

## 보안 기능

- 환경 변수를 통한 민감 정보 보호
- OAuth 2.0 표준 인증
- CSRF 방지 (state 파라미터)
- 토큰 기반 API 인증
- XSS 방지 (Next.js 기본 보안)
