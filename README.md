# rpg-lucky-draw

네이버 카페에서 사용할 랜덤 뽑기 앱을 만들려고 합니다.
RPG 게임을 통해 랜덤 뽑기 기능을 구현할 예정입니다.

## 1차 프로토 타이핑 

막상 해보니 카페 게시글을 가져오는 게 어려웠다.
일단 그것에 집중하기!

- [x] 프로젝트 셋업 
- [x] 네이버 로그인 API 연동
- [x] 네이버 카페 API 연동
- [ ] 랜덤 뽑기 기능 구현
- [ ] 랜덤 뽑기 UI 구현

## 사용 기술

- React + Tailwind CSS + Next.js
- 네이버 로그인 API, 네이버 카페 API

## 앱 흐름

- 네이버 로그인
- 카페 내 게시글 조회
- 해당 게시글에서 '신청' 이라는 단어가 들어간 사용자 닉네임을 리스트로 추출
- 해당 리스트를 이용하여 랜덤한 RPG 캐릭터 생성
- 캐릭터들간 전투를 통해 1명의 승자 결정
- 마지막 장면 캡쳐 후 네이버 카페에 게시글로 게시
