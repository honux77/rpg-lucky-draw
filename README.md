# RPG Lucky Draw 🎮

RPG 스타일의 랜덤 뽑기 앱 - 네이버 댓글 사용자들의 배틀 로얄!

## 개요

네이버 블로그/카페 게시글의 댓글 작성자들을 RPG 캐릭터로 변환하여 토너먼트 방식의 전투를 진행하고, 최후의 1인을 뽑는 프로그램입니다.

### 주요 기능

1. **네이버 댓글 수집**: 특정 게시글의 댓글 작성자 목록 추출
2. **RPG 캐릭터 생성**: 각 사용자를 고유한 능력치를 가진 RPG 캐릭터로 변환
3. **토너먼트 전투**: 1:1 대전을 통해 승자 결정
4. **최종 승자 선정**: 토너먼트를 통과한 최후의 승자 1명 선정

## 설치 방법

### 필요 사항

- Python 3.7 이상

```bash

cd rpg-lucky-draw

# 의존성 설치
pip install -r requirements.txt
```

## 사용 방법

### 기본 사용법

```bash
# 목(mock) 데이터로 테스트 (8명)
python main.py --mock 8

# 네이버 URL에서 댓글 추출 (실제 사용)
python main.py --url "https://blog.naver.com/yourpost/123456"

# 조용한 모드 (전투 상세 과정 생략, 결과만 표시)
python main.py --mock 4 --quiet
```

### 옵션 설명

- `--url URL`: 네이버 블로그/카페 게시글 URL 지정
- `--mock N`: 테스트용 목 데이터 사용 (N명의 가상 사용자 생성)
- `--quiet`: 전투 상세 로그 숨김 (결과만 표시)

## 캐릭터 시스템

각 캐릭터는 다음과 같은 능력치를 가집니다:

- **Level (레벨)**: 1-10 사이의 랜덤 레벨, 모든 능력치에 영향
- **HP (체력)**: 최대 체력, 0이 되면 패배
- **Attack (공격력)**: 공격 시 가하는 데미지
- **Defense (방어력)**: 받는 데미지 감소
- **Speed (속도)**: 전투에서 먼저 공격할 확률 결정

### 전투 시스템

- 속도가 높은 캐릭터가 먼저 공격
- 20% 확률로 크리티컬 히트 (데미지 1.5배)
- 실제 데미지 = 공격력 - 방어력 (최소 1)
- 토너먼트 방식으로 1:1 대결 진행
- 홀수 인원 시 마지막 캐릭터는 부전승

## 네이버 댓글 수집 참고사항

네이버 블로그/카페는 iframe과 동적 로딩을 사용하므로, 실제 환경에서 댓글을 추출하려면 다음 사항을 고려해야 합니다:

1. **네이버 API 인증**: 공식 API 사용 권장
2. **iframe 처리**: 댓글이 별도 iframe에 로드됨
3. **동적 콘텐츠**: JavaScript로 로드되는 내용 처리 필요
4. **Selenium/Playwright**: 동적 페이지 크롤링 도구 사용 고려

현재 구현은 기본적인 HTML 파싱을 제공하며, 프로덕션 환경에서는 추가 개발이 필요합니다.
